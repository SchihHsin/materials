08 / 文案规范
Title

标题写结论，不写导航词

标题脱离版式也应独立成立，直接说清受众要记住的发现或选择。

不写：用户研究 / 方案介绍
写成：文档、调试与环境构成三类核心障碍
Evidence

严格区分证据、推论与方案

证据是事实；推论标明判断；方案是待验证的设计响应，不能把承诺当结果。

用“表明 / 因此判断 / 建议 / 拟通过”明确边界
Design point

方案要说用户能理解、判断或控制什么

每个设计点对应问题、作用机制、用户收益，以及必要的依赖或验证信号。

不写：让体验更清晰、更高效
写成：前置关键状态，让用户知道现在发生什么、下一步能做什么
Tone

书面、简洁、命名一致

去掉口语、空泛词和不常见表达；内容多时拆页，不靠缩字或堆术语。

把复杂概念翻译成听众可判断、可行动的语言
User journey component

用户旅程让每个发现回到具体阶段，而非停留在抽象的“用户痛点”
