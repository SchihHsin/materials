02 · Open-source HTML PPT

04 / 背景

我们的观察是：开源 Skill 已能生成风格化演示，却主要服务单一观点的讲述。

  • 01有标题、留白和翻页，缺少角色、场景与证据关系的专属结构。

  • 03信息密度上升后，结论、证据与设计响应难以形成决策链路。
03 · Extend into a system

通用 Skill 不足的部分，可以从既有能力继续扩展成自己的模板

05 / 背景

扩展的重点不是重做演示，而是把已有能力补成设计师可复用的材料系统。

  • 01补齐用户旅程、画像、竞品与机会矩阵等专属结构。
  • 02把内容路由、表达规则和视觉 token写成可执行规范。
  • 03用翻页、概览和 URL 页码，让材料可讲、可跳转、可复用。

Advantage · Open-source comparison

20 个专属模板页，是通用开源 PPT Skill 的 3.3 倍

08 / 优势

模板页数量对比：同一套设计汇报任务，需要的不是更多同款版式，而是不同信息关系的专属表达。

3.3×倍
BEFORE · 约 6 页

通用模板只能承接基础图文

标题、图片与基础叙述可以完成；遇到旅程、角色关系或机会判断时，往往只能用同一种图文结构拼接，重点关系难以被看见。

AFTER · 20 页

按任务匹配专属模板

用户研究、设计分析、数据进展与设计点各有对应结构；把证据、判断和方案放进合适的表达骨架，无需为复杂内容反复造版。

Advantage · Density and customization

针对内容的按需适配及个性化自定义

09 / 优势

多数开源 PPT Skill 默认使用同一种信息密度：适合单一观点，却难承接研究、项目推进与方案论证中的多层事实。

OPEN-SOURCE DEFAULT轻量图文，密度差别有限

页面结构相近；复杂关系一多，往往只能继续叠加文字或拆散表达。

REPORT PPT SKILL按内容关系切换信息密度

从简洁章节封到研究矩阵、旅程与对照页，让高密度内容仍保留清晰层级。

内容路由：按任务选模板信息密度：按关系调整表达基调：分析 / 设计点章节光晕：颜色与色相视觉强度：亮度与扩散翻页动效：五种节奏可选
Advantage · Narrative and language

语言规范把“怎么写”也纳入 Skill，保证不同材料的叙述质量

10 / 优势

此前，材料生成主要依赖作者或模型的临场判断，即使版式正确，文案仍容易出现标题空泛、证据与方案混写、设计点只讲感受等问题。

  • 把标题、证据、推论与方案的写法明确为可执行规则
  • 要求设计点写清用户能理解、判断或控制什么
  • 统一书面语、命名与信息密度，保证不同材料的表达稳定
