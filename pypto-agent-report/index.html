DESIGN IMPLICATION

Agent 需要的是可验证的“问题对象”，而不是高分辨率像素。

可视化仍应保留给人类建立直觉；但进入模型上下文的载荷必须经过分层、聚合和显式约束编码。

下一步：把流程控制从 Prompt 记忆迁移到运行时逻辑。
RAW TRACE

信息密度与 Token 消耗冲突

单个 trace.rpd 可能包含数百万事件；直接注入上下文无法支持稳定推理。

SEMANTIC ASSET

Trace2Tree 分层事件树

将原始事件重构为阶段、依赖、异常和证据摘要，让 Agent 能按需下钻。

HIDDEN CONSTRAINT

物理约束难以由画面表达

MTE DMA 的 512-byte 对齐、地址 overlap 与流水冲突需要机器可读的规则。

ACTIONABLE DIAGNOSIS

具名约束与修复候选

将地址区间、对齐状态和冲突原因暴露为结构化工具输入与安全修复建议。

PROCESS BELONGS TO RUNTIME

Prompt 只能描述意图；Harness 才能约束过程。

每一次迁移都应携带最小充分证据。Agent 不得从未验证状态直接提交，也不能以“已完成”掩盖缺少的数值、指令或 lint 结果。

Validated Evidence = 状态迁移的必需输入，而非任务结束后的补充说明。
