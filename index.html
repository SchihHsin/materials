Install guide

让 AI 助手安装

打开对应客户端，把右侧整段话复制到输入框中发送。AI 会从 SchihHsin/report-ppt-skill 克隆 Skill 并确认安装完成。

Claude Code
请安装这个全局 Claude Code Skill：
https://github.com/SchihHsin/report-ppt-skill

将仓库克隆到 ~/.claude/skills/report-ppt-skill；若该目录已是这个仓库，则执行 git pull 更新。请保留本地未跟踪文件，不要修改当前项目文件。

安装后，创建 ~/.claude/commands/report-ppt-skill.md，使它读取并使用 ~/.claude/skills/report-ppt-skill/SKILL.md，且将用户输入的参数作为本次汇报需求。这样我可以通过 /report-ppt-skill 来调用它。

确认 Skill 文件和命令文件都存在，并读取它们以确认安装可用。

After installation

重开一次对话，再输入 slash 命令。

在 Claude Code、OpenCode 或 Codex 的输入框键入 /report-ppt-skill，再补充主题、受众、素材与页数要求。

/report-ppt-skill 基于这份调研资料制作一份面向管理层的 10 页产品策略汇报。需要包含核心洞察、用户旅程、竞品比较、方案与 roadmap。
