Install guide

让 AI 助手安装

打开对应客户端，把右侧整段话复制到输入框中发送。AI 会从 SchihHsin/report-ppt-skill 克隆 Skill 并确认安装完成。

Claude Code
请安装这个全局 Claude Code Skill：
https://github.com/SchihHsin/report-ppt-skill

将仓库克隆到 ~/.claude/skills/report-ppt-skill；若该目录已是这个仓库，则执行 git pull 更新。请保留本地未跟踪文件，不要修改当前项目文件。

安装后确认 ~/.claude/skills/report-ppt-skill/SKILL.md 存在，并读取它以确认安装可用。
OpenCode
请安装这个全局 OpenCode Skill：
https://github.com/SchihHsin/report-ppt-skill

将仓库克隆到 ~/.config/opencode/skills/report-ppt-skill；若该目录已是这个仓库，则执行 git pull 更新。请保留本地未跟踪文件，不要修改当前项目文件。

安装后确认 ~/.config/opencode/skills/report-ppt-skill/SKILL.md 存在，并读取它以确认安装可用。
Codex
请安装这个全局 Codex Skill：
https://github.com/SchihHsin/report-ppt-skill

将仓库克隆到 ~/.codex/skills/report-ppt-skill；若该目录已是这个仓库，则执行 git pull 更新。请保留本地未跟踪文件，不要修改当前项目文件。

安装后确认 ~/.codex/skills/report-ppt-skill/SKILL.md 存在，并读取它以确认安装可用。
After installation

重开一次对话，然后直接描述你要的汇报。

Skill 会在“产品汇报、设计方案、用户研究、竞品分析、数据分析 PPT”等请求中自动命中。也可以明确点名它。

使用 report-ppt-skill，基于这份调研资料制作一份面向管理层的 10 页产品策略汇报。需要包含核心洞察、用户旅程、竞品比较、方案与 roadmap。
