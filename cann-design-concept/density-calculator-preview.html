Quantitative Proposal · 01

信息密度不只看字数：先识别阅读形态，再算内容负荷

这是一套“辅助选择页面模板”的量化方案。它不自动决定字体大小，也不替代内容判断。

MAP两阶段路由
原则：意图与主视觉是路线判断；只有 D 系列进入负荷计分

先问：读者这页是在读什么？

相同字数的页面，可能是数据分析、证据解读，也可能是方案展示。把它们放到一条“少到多”的轴上，会得出错误的字号和版式。

先由创作者明确页面意图，避免模型仅凭字数误判“图大但关系复杂”的页面。

STEP 01

页面意图

分析判断，还是呈现设计方案与体验感受？

方案 / 体验 → B 系列
STEP 02

主视觉是否是证据

截图、材料或关系图是否承担主要分析信息？

证据图主导 → A 系列
STEP 03

普通灰底分析

主体由判断、证据、字段和结构化文本构成。

进入负荷计算 → D1--D4

Quantitative Proposal · 02

第一步：先选路线，不计算也能判定 A / B / D

这里不比字数。先看读者要完成的任务，以及图像在这页是否承载关键的信息。

ROUTE先分形态
顺序：先看 B；不是 B 再看 A；都不是时，才进入 D 的量化判断
B 系列

设计叙事：图、界面或机制是主角

读者要感受方案、理解设计点或跟随体验路径。

  • 大图 / 界面 / 路径图承担主叙事
  • 文字只是一句主张与 2--3 条标注
  • 即使关系复杂，也不转成 D4
满足任一项 → B1 大图 / B2 界面标注 / B3 路径机制
A 系列

分析证据：必须看图，才能得出判断

读者是在解读截图、照片、材料或关系图，而非感受设计方案。

  • 图中信息占理解结论的一半以上
  • 不看图就无法理解判断或差异
  • 标注能定位到图中的具体证据
满足以上 → A1 单图解读 / A2 对照图 / A3 关系图
D 系列

普通分析：读文字、数据与结构化字段

图可以存在，但它不承担主要信息；读者主要读判断、证据和行动。

  • 结论主要来自文字、数据或字段
  • 图只做辅助证据或装饰
  • 需要判断内容关系是否变复杂
以上都成立 → 进入下一页 R / I / C / L 计算

Quantitative Proposal · 03

第二步：只有 D 系列需要量化，四项各自计档

理论提供变量来源：认知负荷看元素交互性，认知匹配看比较与查阅任务；不把它们混成一个黑箱权重。

MEASURE如何计算
计算：R / I / C / L 各自落 1--4 档；D 档位取其中最高档

公式很简单：D = max(R, I, C, L)

一页中只要有一项已经需要 D3 的结构，就不能因为其他项较少而降成 D2。强查阅任务则直接到 D4，因为它的阅读目标已经从叙事转为回看与比较。

R 必读文本 · I 同时关联元素
C 横向对照 · L 查阅任务
任一项 4 档，或 L = 强查阅 → D4
R · 必读文本

按需要读完的字与条目计

只算读完才能理解结论的正文与条目；标题、装饰标签不计。

1：≤80 字且≤3 项 · 2：81--160 或 4--5 项 · 3：161--260 或 6--8 项 · 4：>260 或>8 项
I · 元素交互性

按同时需要关联的元素计

元素包括阶段、信号、动作、角色、因果节点；不是所有视觉块。

1：1--3 个 · 2：4--5 个 · 3：6--8 个 · 4：>8 个或跨组互相依赖
C · 横向对照

按同时比较的对象 / 维度计

没有横向比较为 1；单一图表的三根柱不自动等于三维对照。

1：无 / 1 维 · 2：2--3 维 · 3：4--5 维 · 4：>5 维或多维矩阵
L · 查阅任务

按读者的阅读目标计

不是内容多就查阅型；关键是读者是否需要回看字段、责任、依赖或指标。

1：跟随结论 · 2：偶尔回看 · 3：反复查对 · 4：强查阅 / 审阅 / 对照

第三步：最高档位，直接对应 D1--D4 模板

计算的目的不是把字缩小，而是选够用的结构。若渲染后仍拥挤，换结构或组件，不继续减字号。

TEMPLATE结果对应什么
映射：取 max(R, I, C, L) 后，按以下模板处理；视觉拥挤另行验收
D1

结论叙事页

1 个主张 + 2--3 个支撑。主结论是画面最大文字。

R / I / C / L 的最高档为 1
模板：大结论 + 3 张支撑卡 / 短点
D2

标准分析页

1 个判断 + 1 组证据。用一张图、指标组或摘录解释“为什么”。

最高档为 2，且没有强查阅
模板：判断 + 条形 / 数据 / 单组对照
D3

结构化分析页

信息关系变多，用分组、固定模块和短条目承接，正文保持正常字号。

最高档为 3，且没有强查阅
模板：判断 + 信号 + 3--4 个行动模块
D4

查阅 / 对照页

用于明确的审阅、回看、多维比较；优先专属组件，不把内容塞回普通卡片。

最高档为 4，或 L = 强查阅
模板：矩阵 / 表格 / 画像 / 旅程 / 甘特

第四步：用具体页面核对，不是凭感觉选档

每个案例先给出 R / I / C / L 的档位，再展示为何落到相应模板；这就是“怎么算”的完整过程。

EXAMPLES完整演算
案例：页面先是 D 路线；取四项中最高档为 3，因此选 D3 结构化分析模板
D1

结论 + 三个支撑

60 字、3 项、3 个独立支撑，无对照，读者只跟随结论。

R1 · I1 · C1 · L1 → max 1 → D1
D2

判断 + 一组数据证据

130 字、4 项、4 个指标，无需跨组关联或反复回看。

R2 · I2 · C2 · L1 → max 2 → D2
D3

三信号 + 四个设计响应

210 字、7 个元素需串成因果；需要模块化呈现，但不是查阅页。

R3 · I3 · C2 · L2 → max 3 → D3
D4

五环节 × 四字段对照

读者反复比对任务、阻断、责任和响应，目标就是审阅与回看。

R2 · I3 · C3 · L4 → max 4 → D4
A2

两张竞品界面 + 差异结论

虽然可能有 200 字，但核心信息来自两张可比较的界面材料。

先分流 · 图中信息超过一半 → A2
B2

方案界面 + 两个设计标注

图是设计叙事的主体，文字只是帮助观者看懂体验变化。

先分流 · 设计叙事 → B2

最后一道独立检查

视觉拥挤、文字碰撞、局部过密与卡片过碎不进入 R/I/C/L；它们在最终 HTML 渲染后检查，触发结构调整或切换模板。

理论依据在这里怎么用

R/I 来自认知负荷与元素交互性；C/L 来自认知匹配。它们用于定义变量，不声称论文给出了这些具体阈值。
