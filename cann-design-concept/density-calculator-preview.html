Density Rule · 01

一页看清：什么情况下怎么算，算完对应什么布局

先区分阅读形态，再只对普通灰底分析页计算密度。计算结果决定页面结构，不直接缩小字号。

LOGIC条件 → 公式 → 模板
理论依据：R / I 来自认知负荷与元素交互性；C / L 来自认知匹配

不是所有页面都该进入密度计算。

图像讲方案，走 B；图像是分析证据，走 A。只有读者主要在读判断、数据、字段与行动时，才走 D 并量化。

D = max(R, I, C, L)
R 必读文本 · I 同时关联元素
C 横向对照 · L 查阅任务
01 · 先分流

A / B 不计算

设计叙事、界面展示、路径机制为主 → B；必须看截图、材料或关系图才能得出判断 → A。

  • B：大图 / 界面 / 路径是主角
  • A：图中信息占结论的一半以上
02 · 再计算 D

R / I / C / L 各计 1--4 档

R：≤80、81--160、161--260、>260 字；I：1--3、4--5、6--8、>8 个需关联元素。

  • C：0--1 / 2--3 / 4--5 / >5 个对照维度
  • L：跟随结论 / 偶尔回看 / 反复查对 / 强查阅
03 · 选模板

取四项中的最高档

例如 210 字、7 个需关联元素、2 个对照、偶尔回看：R3 / I3 / C2 / L2，最高为 3，所以选 D3。

  • 任一项到 4，或强查阅 → D4
  • 渲染后拥挤 → 换结构，不继续缩字
