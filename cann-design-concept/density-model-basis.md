# 页面密度模型：变量与理论依据

## 适用范围

模型用于文字、数据、字段与行动为主要阅读对象的分析页面。分析图解与设计展示由图像在页面中的阅读角色选择对应布局。

## 计算单位与提取时点

- **计算单位**：一张完成排版、以 16:9 画布导出的页面。
- **可阅读区域**：扣除页面边距、页码、装饰背景和纯留白后的内容画布面积。
- **必读文本**：标题、结论、正文、字段名、数据标签、图例和行动项；品牌标识、页码、来源、纯装饰文字不计入。
- **提取时点**：`T`、`I`、`C` 在布局生成前、按统一测试画布提取，用于选择基础布局。页面生成完成后再计算 `V`，用于视觉验收与细分模板复核。

## 特征定义

| 特征 | 计算方式 | 理论依据 |
|---|---|---|
| `T` 文本负荷 | 必读文本在统一测试画布上的 CSS 渲染字形包围盒面积之和 / 测试画布可阅读区域面积。长段文字逐行计入。 | 认知负荷理论将任务所需信息处理视为认知负荷来源。Sweller (1988)。 |
| `I` 元素交互性 | `(关系边数 / 关系节点数) x (1 + 跨组边数 / 关系边数)`。节点是需要同时理解的指标、角色、步骤或模块；边是显式箭头、连线、对应关系或因果关系。 | 元素交互性是内在认知负荷的核心来源。Sweller (2010)。 |
| `C` 对照负荷 | `(同时比较对象数 x 共同字段数) / 可阅读区域面积`。比较对象指同一判断下横向阅读的方案、角色、时段或产品；共同字段为每个对象都呈现的维度。 | 信息表示形式与任务匹配会影响信息获取和判断。Vessey & Galletta (1991)。 |
| `V` 视觉拥挤 | 对候选页面的渲染截图计算 Feature Congestion，并转换为同一训练页面集合中的百分位。用于复核图文层级、间距与细分模板。 | Feature Congestion 用于量化视觉拥挤。Rosenholtz, Li & Nakano (2007)。 |

## 标准化

四个特征的量纲不同，模型以训练集的稳健统计量统一尺度：

```text
X' = (X - median_train(X)) / IQR_train(X)
```

`median_train` 和 `IQR_train` 与模型版本一起发布。新页面仅使用该版本的固定统计量转换，确保不同页面的得分可以比较。

## 统计模型

对标准化特征使用有序逻辑回归：

```text
z = beta_0 + beta_T*T' + beta_I*I' + beta_C*C'

P(档位 <= k | z) = sigmoid(theta_k - z), k = 1, 2, 3
```

模型参数的职责如下：

| 参数 | 含义 | 如何得到 | 生成时如何使用 |
|---|---|---|---|
| `beta_0` | 基线截距，表示输入特征都处于训练集基准位置时的基础得分。 | 与其余 `beta` 一起由有序逻辑回归拟合。 | 与三项特征的加权结果相加，得到页面连续得分 `z`。 |
| `beta_T` | 文本负荷 `T` 的权重系数。绝对值越大，说明 `T` 对档位变化的影响越大；正值表示文本负荷升高时倾向更高密度。 | 使用已标注页面的 `T'` 与最终采用的 D1--D4 档位拟合。 | 计算 `beta_T * T'`，贡献到 `z`。 |
| `beta_I` | 元素交互性 `I` 的权重系数。 | 使用已标注页面的 `I'` 与最终采用档位拟合。 | 计算 `beta_I * I'`，贡献到 `z`。 |
| `beta_C` | 对照负荷 `C` 的权重系数。 | 使用已标注页面的 `C'` 与最终采用档位拟合。 | 计算 `beta_C * C'`，贡献到 `z`。 |
| `theta_1` | D1 与 D2 的分界点。 | 与 `beta` 同一次拟合，由训练样本中相邻档位的分布学习。 | 比较 `z` 与 `theta_1`。 |
| `theta_2` | D2 与 D3 的分界点。 | 同上。 | 比较 `z` 与 `theta_2`。 |
| `theta_3` | D3 与 D4 的分界点。 | 同上。 | 比较 `z` 与 `theta_3`。 |

`beta` 是**特征权重系数**，回答“哪种负荷对密度档位影响更大”；`theta` 是**档位分界参数**，回答“连续得分在何处切换到下一档”。二者都不是由某一张新页面临时手填，而是由已经确认过最终布局的训练页面统一拟合、随模型版本冻结。

模型将页面映射为结论叙事、标准分析、结构化分析、查阅对照四类布局的概率分布。`V` 在候选页面渲染后独立计算，用于细分布局复核。

| 得分区间 | 基础布局 | 页面骨架 | 细分布局选择 |
|---|---|---|---|
| `z <= theta_1` | 结论叙事 | 一条主张与 2--3 条支撑 | 结论卡、三项支撑、单结论图表 |
| `theta_1 < z <= theta_2` | 标准分析 | 一个判断与一组证据 | 指标组、单图分析、单组对照 |
| `theta_2 < z <= theta_3` | 结构化分析 | 信号组与行动模块 | 问题--机会、信号--动作、模块化卡片 |
| `z > theta_3` | 查阅对照 | 固定字段与矩阵结构 | 竞品矩阵、用户画像、旅程、路线图 |

分析图解和设计展示以图像的阅读角色选择细分布局：证据材料进入单证据图解读、对照图分析或关系图分析；体验主张进入大图主张、界面标注或路径机制。

## 标定与发布

1. 收集已完成的分析页面，按最终采用布局标注类别。
2. 在统一测试画布抽取 `T`、`I`、`C`，以分层交叉验证拟合模型。
3. 拟合时以 D1--D4 的有序标签为因变量，以 `T'`、`I'`、`C'` 为自变量；最大化训练样本中实际档位的有序逻辑回归似然，得到 `beta_0`、`beta_T`、`beta_I`、`beta_C` 与 `theta_1`--`theta_3`。
4. 对每页计算累计概率 `P(档位 <= k | z)`，相邻累计概率相减得到 D1--D4 的概率；默认选择概率最高的档位。最高概率低于发布版本定义的置信阈值时，保留候选档位并进入人工版式复核。
5. 发布 `beta`、`theta`、训练集 `median` / `IQR`、验证样本量、类别准确率、混淆矩阵和置信阈值。
6. 在模型版本文件中固定参数；生成页面按该版本提取特征、标准化并推断布局概率。
7. 渲染候选页面，计算 `V`；根据视觉拥挤度复核图文层级、间距与细分模板。

## 当前模型状态

当前材料定义了特征、公式、训练与发布口径，但尚未建立完成的 D1--D4 标注训练集。因此 `beta`、`theta`、`median`、`IQR` 与置信阈值均为**待标定参数**，不能伪装为已可直接计算的固定数值。

在参数发布前，D1--D4 Demo 用于评审字体层级与布局规则；模型只能作为待实现的计算框架。完成标注、拟合和交叉验证后，必须将实际参数写入一个带版本号的模型参数文件，再将自动判定接入 Skill。
